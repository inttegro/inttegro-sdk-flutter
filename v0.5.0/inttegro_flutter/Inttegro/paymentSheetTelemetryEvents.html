paymentSheetTelemetryEvents property

Stream<PaymentSheetTelemetryEvent> paymentSheetTelemetryEvents
latefinal

Privacy-safe transport diagnostics for a host-owned telemetry pipeline.

Events exclude Order and Payment IDs, customer and payer fields, payment-method details, addresses, bodies, redirect URLs, and raw error messages. They are not authoritative payment state.

Implementation

late final Stream<PaymentSheetTelemetryEvent> paymentSheetTelemetryEvents =
    _telemetryChannel.receiveBroadcastStream().map((value) {
      if (value is! Map) {
        throw const FormatException(
          'Native payment sheet returned an invalid telemetry event',
        );
      }
      return PaymentSheetTelemetryEvent.fromJson(
        Map<Object?, Object?>.from(value),
      );
    }).asBroadcastStream();
