inttegro_flutter library

Inttegro's Flutter SDK for native Checkout payment collection.

This umbrella library preserves the original import surface. Applications may instead import payment_sheet.dart, events.dart, or telemetry.dart when they want API documentation and dependencies grouped by responsibility. The native iOS and Android SDKs still own payment UI, validation, authentication, accessibility, and lifecycle state.
